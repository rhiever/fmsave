# Changelog entries for the per-match records and the table venue

To be folded into `CHANGELOG.md` under `## [Unreleased]`, in `### Changed`, and this file deleted.

### Changed

- A per-match row says what it means by an empty cell. `PlayerMatchStats.rating` is empty for a match the game rated nobody in, where it used to carry `0.0` and sit in the same column as the real ratings of 1.0 to 10.0, so an average over the column was quietly dragged towards zero and nothing in the row said so. `left_at_minute` is empty for a player who was on the pitch at the final whistle, where it used to carry `0`, which read as a substitution before kick-off and made any `left_at_minute < 10` filter for early departures return everyone who played the whole match. Both fields were already `float | None` and `int | None`, and the other thing an empty cell means, that the save no longer holds the match's statistics at all, is told apart by `has_stats`. Nothing is lost: the stored zero rating is kept as `unknown["rating_raw"]`, which is the one value `rating` itself cannot carry, and the minutes a player was on the pitch for are unchanged.

- Two per-match fields are renamed out of the save format's own vocabulary. `PlayerMatchStats.played` is now `has_stats`: it never meant that the player did not play, it meant that the save no longer holds that match's statistics, and a row it is false on still carries the date, the competition and the opponent of a match that was played. `PlayerMatchStats.body_valid` is now `stats_in_range`: it is fmsave's own plausibility flag, not a value the save stores, and "body" is a record layout nothing on a Football Manager screen is called. `fmsave.OUTPUT_SCHEMA_VERSION` stays 2, which this release had already reached; the flat columns `played` and `body_valid` are now `has_stats` and `stats_in_range`, and `unknown_rating_raw` is new.

- `LeagueTableMatch.venue` is now `home_or_away`. It says which side of a match the row's club was, and "venue" read as though it were the same idea as `Fixture.is_neutral_venue`, which says whether a match was played away from the home club's usual ground. The two are independent: a match at a neutral ground still has a home club and an away club. Both fields' documentation now says which of the two it is. The values are unchanged and stay `Venue.HOME` and `Venue.AWAY`.
