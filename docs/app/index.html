Your save never leaves this computer. This page reads it inside your browser with fmsave, an open-source Python reader. Nothing is uploaded and nothing is stored on a server. The page only downloads the reader itself.

Where saves live. On a Mac, ~/Library/Application Support/Sports Interactive/Football Manager 26/games/. On Windows, usually Documents\Sports Interactive\Football Manager 26\games\. A big save takes about half a minute to read. If the game is running, copy the save and drop the copy.

Play fair. CA, PA and hidden attributes are shown. That is fine in your own single-player career. Using them in a shared online career may break its rules.
